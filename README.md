# Sport Rodas — Landing page + painel admin

Site estático (HTML/CSS/JS), sem servidor. Tudo que aparece no site é editável em **admin.html**.

## Como atualizar
1. Abra `admin.html` (senha inicial: a mesma do projeto anterior — **troque em "Segurança e backup"**).
2. Edite textos, fotos, serviços, cores, horários, WhatsApp etc. A prévia ao vivo mostra o resultado.
3. Clique em **Publicar (gerar .ZIP)**, descompacte e suba os arquivos no seu site/GitHub.

## Arquivos
- `index.html` / `style.css` / `script.js`: site público.
- `admin.html` / `admin.css` / `admin.js`: painel (os campos ficam no ESQUEMA em `admin.js`).
- `dados.js`: todos os dados do site (o painel gera este arquivo).
- `core.js`: funções compartilhadas. `imagens/`: fotos.

## Pendente de preencher no painel
Horários de funcionamento e fotos (fachada, oficina, sala de espera) em imagens/.
